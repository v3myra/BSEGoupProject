# BSEGoupProject
UMT LinkUp Website

Proejct Description:

The UMT LinkUp Website is a proposed centralized platform designed to help students of Universiti Malaysia Terengganu (UMT) access information about university events and activities.

The website aims to simplify event discovery by providing event listings, search functionality, event categories and detailed event information in one platform.

Project Objectives:

1. To provide a centralized platform for UMT students to access university event information.
2. To make it easier for students to search and discover upcoming events.
3. To provide clear and organized information about event dates, times, locations and organizers.
